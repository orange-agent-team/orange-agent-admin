# 管理身份、安全与审计边界

管理站使用独立来源和OIDC客户端，E07保存身份令牌，浏览器只持host-only安全cookie。管理cookie为__Host-orange-admin，Secure/HttpOnly/Path=/、SameSite=Lax；不得设置跨用户站的Domain共享cookie。

## 会话流程

1. 初始页面仅显示登录/错误，不加载资源。真实登录由受控E07端点跳转固定IdP/redirect URI，验证state/nonce。
2. 获得管理会话后读取角色、scopes、permissions、MFA/step-up与CSRF。普通用户会话或组织admin不满足平台认证。
3. 每次写入发送当前CSRF和精确Origin；高风险执行由后端验证最近15分钟的step-up。空闲15分钟/绝对8小时和审批60分钟沿原设计默认，实际值入版本化配置。
4. 权限撤销/401/403时清理相应缓存和待批准交互；已派发效果按业务ID核对。重新登录不得自动重放页面遗留的写请求。
5. 注销调用服务器撤销会话，清理内存缓存与敏感视图，浏览器后退不能恢复私有内容。

## 权限组合

动作创建/执行需要actions通用权限与具体动作permission；批准需要actions.approve和approval_permission，另加实际scope及不同主体条件。角色模板不是万能超级管理员。后端控制审计/角色变更/资金/资源状态，UI守卫仅提示当前可用动作。

模型、普通API key、MCP和插件不能成为平台审批人。平台bootstrap无默认账号密码，管理员开通/恢复按受控身份与审计流程实施；前端不提供隐式后门。

## 浏览器数据与日志

管理响应no-store，不设置持久化Query缓存或离线Service Worker。请求缓存键至少包含principal、session_generation、environment、scope、资源/查询参数；不同账号/范围不复用详情。SupportContent不进入全局持久缓存、URL参数、分析埋点或错误上报正文。

不可信名称/描述/用户输出按文本或受限Markdown显示，链接导航需明确目的地，禁任意HTML/脚本。构建变量只能含非秘密配置；错误上报使用错误码、构建号、correlation与经审阅的字段。

## 高风险操作

请求必须有目标版本、原因、工单、明确payload和范围；批准预览显示其完整业务含义。确认之后内容变化必须新建动作。支付/冲正、角色授予、节点恢复、模型启用、价格发布、扩大上线、重新开启功能、支持访问使用独立批准。

紧急止损可以关闭新工作，但不抹掉在途事实；恢复需证据和批准。前端不提供set_balance、force_idle、任意数据库/系统Shell或秘密查看器。

## 审计

E07持久审计与状态/命令事务关联；浏览器埋点不能代替。查询和敏感取回也要留下主体、资源/范围、目的、时间与结果。用户授权访问不等于可读凭证；已下载副本不能承诺远程强制收回。保留时长由经营/地区政策登记，不在前端写死。

身份/step-up/SupportGrant撤销等协议缺口见[接口准备](api-integration.md)，必须在对应真实功能开放前关闭。
