# 独立构建、部署与回退准备

E11独立版本发布，E07仍是管理API的唯一领域后端。当前未创建CI配置、包清单、域名或部署资源。

## 环境与配置

dev/staging/production各自管理来源、IdP client、API环境与测试数据，生产构建不得回退到开发默认。前端只读取非秘密的API基路径、构建版本和能力清单；错误上报DSN等如使用也须登记数据去向。OIDC、支付、数据库和签名私钥仅在受控服务端保存。

管理来源提供静态SPA并将/admin/v1代理到允许的E07环境。不得用用户Web的跨域cookie共享登录；代理必须保留服务端安全头、ETag及no-store语义。Content Security Policy和依赖资源来源清单经实际构建验证，不能以允许任意inline脚本绕过问题。

## 发布步骤

1. 固定Admin源码、依赖、工具链与服务端契约摘要，完成类型/构建、schema样例及授权/幂等/浏览器回归。
2. 保存不可变静态制品、文件摘要、依赖/许可清单及旧版制品；不把安装依赖和实际部署合成不可审阅的隐式脚本。
3. 在staging用真实管理会话和隔离领域环境验证；替身结果单列。
4. 后端先提供兼容API，再灰度Admin；先只读，再逐动作/角色/环境scope启用写入。独立批准政策永远由后端执行，前端开关不能弱化它。
5. 观察错误、权限拒绝、请求延迟、unknown case与审批滞留；不采集原始用户内容或密钥作为前端诊断。

管理站发布不要求用户Web同一时刻上线；但共同契约变更需两端分别验证，不能只因组件相同就复用结果。

## 兼容记录

记录Admin build/commit（实际存在后）、Node/依赖锁、API/schema版本与摘要、支持的E07构建、会话/policy版本和浏览器build。当前无Git，不填虚构commit。服务端0.1.0草案快照有实际文件SHA，不能因此宣称其API已经部署。

变更共享组件时通过版本包或独立提交升级，不使用相邻仓库src相对引用进行生产构建。移除旧版本支持沿原CX窗口执行，安全紧急撤销有单独原因/替代版本及在途处理。

## 回退与事故

静态资源可以切回已验证旧版本，但不能回滚账本、清空审批或重发上次付款。旧UI不理解新state/必需字段时只读/拒绝，保留升级入口；无法兼容时关闭相关写入口，使用相同政策CLI核对。

发布故障先停止新受影响操作，当前action/退款/设备保持查询和处置路径。证书/IdP异常不得临时关闭鉴权；角色缓存或前端包泄漏时撤销相应身份/版本并保留审计。服务端权限/事务和未知结果手册不由页面回退替代。

运营恢复需要真实主备值守和领域负责人批准，PREP-10/12未关闭前不能标生产就绪。
